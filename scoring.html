配置 Firebase Realtime Database 後，線上評審、大螢幕與主辦總表將跨越不同家用網路進行毫秒級即時同步（大螢幕跳題評審秒翻頁、打分秒進主辦總表）。
💡 貼上 const firebaseConfig = { ... }; 或純 JSON 格式皆可自動辨識。資料保存在您本機瀏覽器。
📖 如何在 1 分鐘內免費取得 Firebase 設定代碼？
  1. 使用一般 Google 帳號登入 Firebase Console。
  2. 點擊「新增專案」，輸入專案名稱（例：chinese-vocab-comp）。
  3. 在左側選單點擊「Build」➔「Realtime Database」➔「建立資料庫」，位置選預設，安全性規則選擇「以測試模式啟動 (Test Mode)」。
  4. 點擊專案首頁齒輪圖示「專案設定」➔ 在下方「您的應用程式」點擊網頁圖示 </> 註冊應用程式。
  5. 複製畫面中顯示的 firebaseConfig 物件內容，貼入上方文字框並點擊「儲存」即可！
