# 🏆 臺灣正體中文 識字比賽播放系統

專為線上識字比賽（透過 Zoom、Google Meet、Microsoft Teams 等螢幕分享）設計的高清晰度字詞播放工具。  
**本專案全數採用臺灣正體/繁體中文，無混雜簡體字。**

---

## 🌟 核心特色與問題解決方案

### 1. 🛡️ 專業封面防洩題設計
* **解決以往痛點**：舊版使用 PPT 播放時，老師一分享螢幕就會讓學生提早看到第 1 題。
* **全新防護機制**：
  * 開啟後固定停留在專業大氣的**比賽封面頁**，顯示比賽標題、競賽級別、題數及可選填的參賽選手姓名。
  * 點擊「開始比賽」後，具備 **3... 2... 1... 倒數準備動畫**（亦可關閉），讓主持老師與學生有充分準備時間，倒數完畢才正式切入第 1 題。
  * 比賽完畢後自動進入「**完賽總結頁**」，避免突兀結束或提早洩漏後續畫面。

### 2. 🖋️ 臺灣教育部標準標楷體保證（美國電腦專屬解決方案）
* **解決以往痛點**：許多海外或美國華語文學校老師使用英文版 Windows、Mac 或 Chromebook，系統常未預裝臺灣標楷體，容易退化為系統黑體甚至日文字形，筆畫結構不同（如「辶」、「骨」、「門」等寫法差異），使年幼學童辨識困難。
* **三大保證方案**：
  1. **本機內建開源楷書 (`fonts/Iansui-Regular.ttf`)**：專案自帶臺灣教育部標準楷書字型，即使在完全離線無網路的美國電腦上，也能百分之百保證顯示正統標楷體！
  2. **線上 WebFont 雙重備援**：支援雲端 CDN 動態加載臺灣標準芫荽楷書。
  3. **自訂字型拖曳載入**：設定中提供字型拖曳上傳功能，老師可自行載入喜愛的 `.ttf` / `.otf` 字型。
  4. **清晰加粗與大小縮放**：文字自適應螢幕大小（1~4字超大置中不折行），並支援字體大小微調與筆畫加粗，確保視訊壓縮下依然清晰銳利。

### 3. ⏱️ 播放間距秒數靈活調整
* **各級別專屬預設秒數**：
  * **第一級 (Level 1)**：預設 **2.5 秒**
  * **第二級 (Level 2)**：預設 **2.0 秒**
  * **第三級 (Level 3)**：預設 **2.0 秒**
  * **第四級 (Level 4)**：預設 **1.5 秒**
* **操作者自由微調**：
  * 比賽開始前可在封面頁自由輸入或調整秒數。
  * 播放中亦可使用懸浮控制列的 `-0.5s` / `+0.5s` 即時增減。
  * 提供平滑的**倒數計時進度條**，讓操作者與學生一目了然（可依需求在設定中開關）。

### 4. 📚 題庫管理與抽考題數控制（解決大題庫過度耗時問題）
* **內建官方題庫**：初次啟動已內建 4 個級別共 **465 個標準臺灣正體詞彙**（含第一級 50 題、第二級 54 題、第三級 105 題、第四級 206 題）。
* **🎲 預設抽考 50 題機制**：
  * **特別針對 Level 3 (105題) 與 Level 4 (206題)**：以往全考耗時過長，系統預設為每位選手隨機抽考 **50 題**（可於封面頁或設定視窗中自由自訂題數，亦可勾選「考全部」）。
  * 每次開始時自動從題庫中隨機抽出 50 題，兼顧考試鑑別度與比賽進度節奏！
* **自主題庫維護**：
  * 支援多行文字框快速貼上新題目（一行一個詞彙），隨打即存。
  * 一鍵「🧹 自動整理格式」功能，去除多餘空行與空格。
  * 支援「➕ 新增自訂級別」與「🗑️ 刪除級別」。
  * **預設勾選「🔀 題目隨機順序出題」**，每位選手皆為全新隨機排列，防止背題。
  * **永久儲存**：設定與題庫皆自動保存在瀏覽器本地快顯（LocalStorage），重新整理或重開機資料絕不遺失。
  * **匯入與匯出備份**：支援一鍵匯出為 JSON 題庫檔案，方便分享給其他評審與老師。

### 5. ✏️ 2026 年度比賽標題自訂
* 預設標題為 **2026 TACSFL 識字比賽**。
* 進入「⚙️ 設定與題庫」，可隨時修改「比賽名稱 / 標題」（如：`2026 TACSFL 識字比賽`）與「副標題」，封面、導覽列與全螢幕抬頭即時更新。

### 6. 🎙️ 學生自主練習與 AI 聽音評分模式（全新重大升級）
* **大會官方 100 分制標準**：
  * 每級隨機抽考 **50 題**，每題滿分 **2.0 分**，總分 **100 分**。
* **💡 發音準確度評估（1.0 分）**：
  * 字音認讀準確，聲母、韻母、聲調無誤；變調（一、不、三聲變調）、輕聲自然。
  * 每讀錯一個字音扣 **0.5 ~ 1.0 分**。
* **🏃 流暢連貫度評估（1.0 分）**：
  * 速度適中不拖腔，無不當停頓，無重複、回讀或口吃斷續。
  * 每停頓卡頓或重複回讀一次扣 **0.5 分**。
* **🔒 單題隔離防倒扣機制**：
  * 每題最低 0 分扣完為止，**絕不倒扣到下一題分數**。
* **🤖 多模態語音大模型驅動**：
  * 採用最新 Google **Gemini 3.5 Flash** 多模態音訊引擎，非同步背景評測，倒數計時播放極致流暢不卡頓。
  * 支援免信用卡 API 密鑰配置，安全存於本地瀏覽器。
* **📊 專業診斷成績單與錄音回放**：
  * 總分與評等徽章（🏆 特優 / 🥇 優等 / 🥈 甲等 / 🥉 良好 / 努力中）。
  * 滿分題數、發音扣分、卡頓扣分與總扣分統計。
  * **50 題全量詳細清單**：精確標註扣分原因、AI 診斷糾音建議。
  * **🔊 原音回放**：家長與老師可直接點擊每題喇叭按鈕，回聽學生當下的實際朗讀音檔！
  * **🖨️ 列印與 PDF 匯出**：內建專屬列印樣式，可一鍵另存為精美證書成績單。
  * **🔄 錯題精準加強練習**：一鍵將扣分題目獨立取出，進行針對性補強練習。

## 🚀 啟動與使用方法

本工具提供兩種極為簡便的啟動方式：

### 方式一：直接以瀏覽器開啟（最推薦，無需安裝任何環境）
1. 在資料夾中找到 [`index.html`](index.html)。
2. 使用滑鼠**連按兩下（雙擊）**，以 Google Chrome、Microsoft Edge 或 Safari 開啟即可直接使用！
3. （所有題庫與本地字型已配置為本機直接相容，無需網路即可離線運作）。

### 方式二：使用 Windows 啟動檔 / Python 本地伺服器
* **Windows 使用者**：連按兩下 [`啟動識字比賽系統.bat`](啟動識字比賽系統.bat)，程式將自動啟動本地服務並為您開啟瀏覽器。
* **或使用命令列**：
  ```bash
  python run_server.py
  ```

## ⌨️ 鍵盤快速鍵操作指南

在比賽進行時，使用鍵盤操作可避免滑鼠干擾畫面：

| 按鍵 | 功能說明 |
| :--- | :--- |
| **空白鍵 (Space)** | 暫停 / 繼續播放（封面頁時則為開始比賽） |
| **方向鍵右 (→) / Enter** | 手動切換至下一題 |
| **方向鍵左 (←)** | 返回上一題 |
| **R 鍵** | 重播當前題目的計時 |
| **F 鍵** | 切換全螢幕模式（全螢幕投影） |
| **Esc 鍵** | 結束播放並返回封面頁 / 關閉設定視窗 |

> 💡 **螢幕分享小秘訣**：進入全螢幕播放後，若滑鼠靜止約 2 秒，頂部與底部的控制面板會自動淡出隱藏，留下最乾淨純粹的白底黑字；移動滑鼠即可再度呼出控制項。

## 📁 專案檔案結構

* [`index.html`](index.html)：系統主頁面（包含封面、倒數、播放、結算四大畫面）。
* [`style.css`](style.css)：專用樣式表（大字體自適應、教育部標楷體定義、計時動畫）。
* [`app.js`](app.js)：核心邏輯（計時迴圈、題庫管理、字型加載、音效產生器）。
* [`default_bank.js`](default_bank.js)：2024 年官方題庫資料（Level 1 ~ 4，共 465 題）。
* [`default_bank.json`](default_bank.json)：官方題庫之 JSON 格式備份檔。
* `fonts/Iansui-Regular.ttf`：開源臺灣教育部標準標楷體字型檔（提供 100% 離線字型支援）。
* [`run_server.py`](run_server.py)：輕量級本機 Web 伺服器啟動腳本。
* [`啟動識字比賽系統.bat`](啟動識字比賽系統.bat)：Windows 桌面一鍵啟動捷徑。

## 🌐 如何發布至 GitHub 並分享給其他老師（GitHub Pages 線上免安裝指南）

本專案為**純前端靜態架構**，完全相容 **GitHub Pages**。您可以將此專案免費發布為公開線上網站，讓其他學校老師、家長與學生**無需安裝任何環境或下載壓縮包**，用手機、iPad、Chromebook 或電腦瀏覽器直接打開即可使用！

### 步驟一：上傳程式碼至 GitHub
1. 在 [GitHub](https://github.com/) 登入您的帳號，點擊右上角 **`+` -> `New repository`**（新建倉庫）。
2. 設定倉庫名稱（例如：`chinese-vocab-competition`），可設定為 **Public（公開）**。
3. 將本資料夾內的檔案推送（Push）或直接拖曳上傳至該倉庫的主分支（`main`）。

### 步驟二：開啟免費 GitHub Pages 線上網站
1. 在您的 GitHub 倉庫頁面中，點擊上方選單的 **`Settings`（設定）**。
2. 在左側側邊欄中，點擊 **`Pages`**。
3. 在 **Build and deployment** 下方的 **Branch** 選單中：
   * 選擇 **`main`**（或 `master`）；
   * 資料夾保持預設的 **`/(root)`**；
   * 點擊 **`Save`（儲存）**。
4. 等待約 1 分鐘重新整理頁面，GitHub 就會產生專屬的線上專案網址（例如：`https://<你的GitHub帳號>.github.io/chinese-vocab-competition/`）。

### 步驟三：分享給其他老師使用
* **直接分享網址**：把生成的 GitHub Pages 網址發給其他老師或學生，點開即可直接進行比賽播放或自主練習。
* **AI 聽音評分設定（安全免綁卡）**：
  * 其他老師或學生如需使用「🎙️ AI 聽音評分模式」，只需點擊右上角 **「⚙️ 設定與題庫」->「🎙️ AI 評分設定」**，填入個人的免費 Google AI Studio Key 即可。
  * **隱私保證**：Key 僅會保存在各自電腦的瀏覽器本地快顯（LocalStorage），絕不會上傳雲端或外洩給他人，也完全不消耗您的個人配額。
  * **快捷分享連結**：亦可透過 `https://<網址>/#key=您的Key` 快速讓同班級學生直接套用 Key（載入後自動清除網址列參數）。

### 💡 附錄：其他老師如何 10 秒取得免費 Google AI Key（免信用卡）
1. 使用平常的 Google / Gmail 帳號登入 [Google AI Studio](https://aistudio.google.com/)；
2. 點擊左上角或畫面中的 **`Get API key`** 按鈕；
3. 點擊 **`Create API key`**，複製產生的金鑰代碼；
4. 回到識字比賽系統，在「⚙️ 設定」->「🎙️ AI 評分設定」貼上並點擊「儲存」即可永久免費使用！
